Team Expense Manager

Project Description

Team Expense Manager is a Spring Boot application used to manage and track team expenses.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST API
- Swagger UI
- Maven

Features

- Create and manage users
- Create and manage events
- Add team expenses
- Retrieve expense details
- Validate request data
- Handle exceptions
- REST API integration

Tools

- Eclipse IDE
- Postman
- Swagger UI
- Git and GitHub
